# Gym Galaxy React Application

A modern React.js application for a gym website with responsive design and component-based architecture.

## Features

- **Responsive Design**: Mobile-first approach with responsive layouts
- **Component Architecture**: Modular React components for maintainability
- **Modern UI**: Clean, modern design with smooth animations
- **Interactive Navigation**: Smooth scrolling navigation with mobile menu
- **Service Sections**: Showcase gym services and pricing plans

## Components

- **Header**: Navigation bar with mobile menu
- **Home**: Hero section with call-to-action
- **Services**: Grid of gym services
- **About**: Information about the gym
- **Plans**: Pricing plans with features

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

3. Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

### Building for Production

```bash
npm run build
```

This builds the app for production to the `build` folder.

- Modify component styles in respective CSS files
